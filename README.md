# Operating Systems Practicals

A collection of Operating System practical programs implemented in **C**, covering fundamental concepts of Operating Systems, including process management, CPU scheduling, memory management, disk scheduling, synchronization, and more.

## 📚 Topics Covered

### 1. CPU Scheduling Algorithms
- First Come First Serve (FCFS)
- Shortest Job First (SJF – Non-Preemptive)
- Shortest Remaining Time First (SRTF)
- Longest Job First (LJF – Non-Preemptive)
- Longest Remaining Time First (LRTF)
- Priority Scheduling (Preemptive & Non-Preemptive)
- Round Robin Scheduling

### 2. Memory Management
- Contiguous Memory Allocation
- First Fit Allocation
- Memory Allocation Techniques

### 3. Disk Scheduling Algorithms
- FCFS Disk Scheduling
- Other Disk Scheduling Techniques

### 4. Page Replacement Algorithms
- FIFO (First In First Out)
- LRU (Least Recently Used)
- Other Page Replacement Techniques

### 5. Process Management
- Process Creation using `fork()`
- Process Execution using `exec()`
- Parent and Child Processes

### 6. Process Synchronization
- Dining Philosophers Problem
- Producer-Consumer Problem
- Readers-Writers Problem
- Threads and Multithreading

### 7. Deadlock
- Banker's Algorithm

## 🛠️ Technologies Used

- **Language:** C
- **Operating System:** Linux / Windows (where supported)
- **Compiler:** GCC

## 🚀 How to Run

Compile a C program using GCC:

```bash
gcc filename.c -o output
```

Execute the compiled program:

**Linux:**
```bash
./output
```

**Windows:**
```bash
output.exe
```
